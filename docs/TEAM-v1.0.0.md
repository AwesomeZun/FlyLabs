# FlyLabs 팀 역량

강성준은 서울대학교 의과학 박사로, 바이오기업에서 항체 신약개발을 이끌고 단일세포·공간 데이터 분석 체계를 구축했습니다. 연세대학교 원주의과대학에서는 영상·유전자 발현·임상 정보를 통합하는 AI 연구를 수행했습니다. 실험과 데이터 분석을 모두 경험해 연구 현장의 문제를 서비스 기능으로 구체화할 수 있습니다. 경력: https://kangseongjun.com

『의료 바이오 연구자를 위한 AI 신약개발 실전 가이드』 공저자이며, 지피터스 신약개발·뇌과학 스터디장으로 AI 활용 교육과 사례 공유를 진행했습니다. 연구자의 질문을 파악하고 전문 기술을 쉽게 설명하는 경험을 갖추고 있습니다.

OpenShell 기반 보안 AI 에이전트와 신약개발·약물감시 CLI(명령어로 사용하는 도구)를 설계한 경험이 있습니다. 이를 바탕으로 연구데이터의 외부 전송과 AI의 실행 권한을 통제하는 FlyLabs 구조를 구체화하고 있습니다.

FlyGate와 K-BeautyGate로 NVIDIA 해커톤 Top 5 결승에 진출했으며, 결승전은 11월 NVIDIA 공식 행사에서 개최될 예정입니다. 웹 서비스 기획부터 개발·배포까지 직접 수행했습니다. 관련 프로젝트: https://flygate.kr / https://k-beauty-gate-zeta.vercel.app/bunny

초파리 신경 연결 데이터를 활용한 FDDD·FlyBrain과 ToYZ 서비스도 개발했습니다. FlyLabs는 자료 비교·준비표·연구노트를 연결한 공개 체험판을 배포했으며, 별도의 서버용 시제품에서 계정·권한·수정 이력·AI 연결 기능을 구현했습니다. 시제품: https://flylabs-research.vercel.app

하버드 의과대학·MGH에서 림프관 질환과 암 전이를 연구하는 노강산 박사, 피부과 임상·연구 경험을 갖춘 Demehri 연구실의 임성하 박사후연구원과 협력해 현장 요구사항을 확인하고 실증 테스트를 추진할 계획입니다. 연구·교육·개발 경험을 실제 사용자의 현장 검증과 연결하는 것이 강점입니다.
