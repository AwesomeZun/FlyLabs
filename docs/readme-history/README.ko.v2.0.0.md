# FlyLabs v2.0.0

**실험 계획, 실제 수행, 관찰 결과와 해석을 연결하는 연구실 랩노트입니다.**

개인 연구 노트로 시작해 동료를 초대하고, 실험별 준비·자원·파일·기록을 함께 관리할 수 있습니다.

## 시작

Node.js 22.16 이상이 필요합니다. 현재 검증 환경은 Node.js 22.22.3입니다.

```sh
cd /Users/kang/orca/projects/FlyLabs/v2.0.0
npm ci
npm run dev
```

[FlyLabs 열기](http://127.0.0.1:4190) → **회원가입**으로 자신의 계정을 만드세요. 기본 계정이나 공용 비밀번호는 없습니다. 처음 가입한 계정이 이전 버전에서 옮긴 연구실의 관리자가 됩니다. 이후 계정은 각자의 개인 연구실에서 시작합니다.

빌드된 앱은 `npm run build` 후 `npm start`로 실행하며, [4191 포트](http://127.0.0.1:4191)에서 사용할 수 있습니다. 같은 데이터 폴더로 API 서버를 두 개 실행하지 마세요.

## 랩노트 사용 흐름

1. **랩노트 → 새 실험·노트**에서 실험명, 프로젝트, 담당자, 예정일을 등록합니다.
2. **실험 계획**에 목적, 가설, 설계, 시료·재료·조건, 절차를 작성합니다.
3. **실행 기록**에 실제 수행한 일을 남깁니다. 잘못 적은 내용은 원문에 연결한 정정 기록으로 수정합니다.
4. **결과·해석**에서 관찰 사실, 분석·해석, 결론, 한계, 다음 단계를 나누어 정리합니다.
5. **노트 저장**을 누르면 계정, 시각, 수정 이유와 이전 내용을 함께 보존합니다. 동시에 수정하면 이전 리비전으로 새 내용을 덮어쓰지 못합니다.
6. 검토를 마치면 **검토 후 서명**으로 해당 리비전을 잠급니다. 추가 수정은 이유를 적고 **새 리비전 열기**로 이어갑니다.
7. 개별 노트는 Markdown으로, 여러 실험은 인수인계 초안으로 내려받습니다.

작성 중인 내용은 현재 브라우저 탭에 임시 보관됩니다. 서버 저장을 대신하지 않으며, 탭을 닫거나 로그아웃하면 사라질 수 있으므로 작업을 마칠 때 저장하세요.

앱 내 서명은 로그인 계정의 검토 확인과 편집 잠금입니다. 공인 전자서명이나 규제 준수 인증은 아닙니다. 실험 진행 상태와 일반 진행 메모는 서명한 노트 본문과 별도로 관리합니다.

## AI 사용

**Jev**는 진행 메모의 의미를 분류해 실험 상태 변경을 제안합니다. 선택한 메모와 실험명·현재 상태만 TypeSafe에 전송합니다. 사람이 원문을 보고 반영하기 전에는 상태를 바꾸지 않습니다.

**Gemini**는 사용자가 선택한 원문을 계획 또는 결과 초안으로 정리합니다. 현재 노트, 최근 실행 기록, 100 KB 이하 UTF-8 텍스트·CSV·JSON 파일 최대 3개를 선택할 수 있습니다. 선택하지 않은 파일은 전송하지 않습니다.

초안에는 사용한 원문과 출처가 함께 남습니다. 빠진 정보는 확인 질문으로 표시하고, 사람이 선택한 항목만 검토 후 교체합니다. 계획 초안이 관찰 결과·결론을 채우는 것은 서버에서 차단합니다. 출처 ID 검증이 과학적 정확성을 보증하지는 않으므로 수치·조건·해석을 확인하고 반영하세요.

지정된 기존 `.env`를 서버에서 읽도록 연결했습니다. 원본 파일은 수정하지 않았으며 키를 화면이나 소스 코드에 넣지 않았습니다. **Jev 상태 판단과 Gemini 계획·결과 정리는 가상 데이터로 실호출 검증했습니다.** 사용 모델은 `jev-1.13.0`, `gemini-3.1-flash-lite`입니다.

## 동료와 함께 사용

설정에서 동료의 이메일과 권한을 선택해 초대 링크를 만듭니다. 링크는 7일 동안 한 번만 사용할 수 있으며, 수락 전 취소할 수 있습니다. 초대받은 이메일 계정으로 로그인하고 링크를 열면 연구실에 참여합니다.

- **관리자:** 초대, 접근 권한 변경, 기록 관리
- **편집자:** 노트·기록 작성, 파일 연결, AI 검토
- **열람자:** 읽기와 내보내기

작성자는 로그인 계정으로 고정됩니다. 권한을 해제해도 기존 작성 기록은 보존합니다. 동료의 변경은 화면 복귀 시와 15초 간격으로 확인합니다.

이메일은 로그인 식별자이며, 메일 인증·자동 초대 메일·비밀번호 찾기 메일은 제공하지 않습니다. 초대 링크는 직접 전달하세요. 현재는 로컬에서 실행 중이므로 다른 컴퓨터에서 접속하려면 HTTPS 서버 배포가 필요합니다. 공개 배포는 수행하지 않았습니다.

## 저장과 백업

계정·기록은 `.data/flylabs.sqlite`, 첨부 원본은 `.data/uploads/`에 저장됩니다. 파일당 최대 10 MB를 지원하며 원본과 SHA-256 해시를 보존합니다.

```sh
npm run backup -- /새로운/백업폴더
node scripts/backup.mjs verify /백업폴더
node scripts/backup.mjs restore /백업폴더 /새로운/복원데이터폴더
```

전체 백업은 데이터베이스와 첨부 원본을 함께 보관하고 해시를 검증합니다. 기존 폴더를 덮어쓰지 않습니다. 복원 후 `FLYLABS_DATA_DIR`를 새 데이터 폴더로 지정하고 다시 로그인하세요. 백업에는 계정 비밀번호 해시와 연구 기록이 포함되므로 비공개로 보관해야 합니다. API 키는 백업하지 않습니다.

설정의 JSON 내보내기는 기록과 파일 목록을 내려받는 기능이며 파일 원본을 포함한 전체 백업과는 다릅니다.
